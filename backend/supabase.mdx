Supabase gives your Rork app a Postgres database with Row Level Security, authentication, and storage. You can connect an existing Supabase project, or let Rork help you create one.

## The easiest way: just ask in chat

You can skip the manual setup below entirely. In your project chat, ask Rork:

```text
Add a backend to my app
```

Or, if you specifically want Supabase under your own account:

```text
Add a Supabase backend to my app
```

Rork walks you through connecting it. If the backend runs under your own Supabase account, Supabase bills you directly on [their pricing](https://supabase.com/pricing). If you would rather have Rork host the backend for you with no separate account, see [Rork Cloud](/backend/rork-cloud).

## Manual setup

<Steps>
  <Step title="Create a new Supabase project">
    Go to [Supabase](https://supabase.com/) and click **New project**. Name it, choose a region, and wait for it to provision.
  </Step>
  <Step title="Copy your project credentials">
    In your Supabase project, go to **Project Settings → API**. Copy the **Project URL** (anon/public key) and the **Service role** key.
  </Step>
  <Step title="Paste them into Rork">
    Open your Rork project and send this prompt, pasting the values you just copied:

    ```text
    Connect Supabase. Here are my credentials:
    Project URL: [paste here]
    Anon key: [paste here]
    ```

    Rork will instruct you on any additional setup needed.
  </Step>
</Steps>

## What to do next

Once Supabase is connected, you can ask Rork to:

- Set up user authentication (email/password, OAuth, magic links)
- Create database tables and RLS policies
- Build server-side Edge Functions for private API calls

If you want to add OAuth (Sign in with Apple or Google), see [Add Sign in with Apple or Google](/integrations/backend/how-to-set-up-oauth).

If you want to connect a third-party API via an Edge Function, see [Connect an API to your app](/features-apis/apis/how-to-connect-an-api-to-your-project).
