---
title: "How to add a Supabase backend to Rork"
---

This guide will help you create a Supabase backend for your Rork project. This includes authentication for users and also custom database schemas for functionalities in your app.

## The easiest way: just ask in chat

You can skip the manual setup below entirely. In your project chat, ask Rork:

> Add a backend to my app

or, if you specifically want Supabase under your own account:

> Add a Supabase backend to my app

Rork walks you through connecting it. If the backend runs under your own Supabase account, Supabase bills you directly for it on [their pricing](https://supabase.com/pricing). If you would rather have Rork host the backend for you, see [What is Rork Cloud](/backend/rork-cloud).
