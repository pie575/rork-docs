Guía completa para conectar tu proyecto de Rork con GitHub y tener una sincronización bidireccional

<div id="why-would-you-want-to-enable-github-sync">
  ## ¿Por qué activar la sincronización con GitHub?
</div>

Conecta **GitHub** si quieres llevar tu app de Rork más allá del editor de Rork y trabajar con herramientas de desarrollo tradicionales.

<div id="github-lets-you">
  ### GitHub te permite:
</div>

* **Compartir tu proyecto con un desarrollador** para colaborar o personalizarlo
* **Abrir y editar tu app en Cursor o en cualquier editor de código**
* **Ejecutar y depurar el proyecto en Xcode** para el desarrollo en iOS
* **Hacer cambios a nivel de código** que van más allá de la creación basada en prompts

GitHub actúa como puente entre **Rork** y los flujos de trabajo de desarrollo profesional, facilitando traspasos fluidos, personalización y desarrollo nativo.

Si trabajas exclusivamente dentro de Rork, GitHub es opcional.
Si quieres más control, colaboración o herramientas nativas, te lo recomendamos.

<div id="what-you-can-do-now">
  ## Qué puedes hacer ahora
</div>

Con GitHub conectado, tu proyecto de Rork ya no se limita al editor de Rork. Ahora puedes:

* **Entregar tu proyecto a un desarrollador**
  Comparte el repositorio para que un desarrollador pueda clonarlo, editarlo y subir cambios.
* **Abrir el proyecto en Cursor o en un editor de código**
  Inspecciona y modifica el código generado con Cursor, VS Code o cualquier IDE.
* **Ejecutar y depurar la app en Xcode**
  Compila en local, prueba en dispositivos reales y usa las herramientas de depuración nativas de Apple.
* **Personalizar más allá de los prompts**
  Haz cambios precisos a nivel de código, añade funciones nativas o afina el rendimiento.
* **Trabajar en paralelo con Rork**
  Sigue construyendo en Rork mientras se realizan cambios desde GitHub.

Esta integración te permite pasar sin fricciones de la **creación basada en prompts al control total del código**, cuando quieras.
