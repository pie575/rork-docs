title: "Cómo añadir un backend de Supabase a Rork"
---

Esta guía te ayudará a crear un backend de Supabase para tu proyecto de Rork. Incluye la autenticación de usuarios y también esquemas de base de datos personalizados para las funcionalidades de tu app.

<div id="the-easiest-way-just-ask-in-chat">
  ## La forma más fácil: pídelo en el chat
</div>

Puedes saltarte por completo la configuración manual que se describe abajo. En el chat de tu proyecto, pídele a Rork:

> Añade un backend a mi app

o, si prefieres usar Supabase con tu propia cuenta:

> Añade un backend de Supabase a mi app

Rork te guía paso a paso para conectarlo. Si el backend se ejecuta en tu propia cuenta de Supabase, Supabase te lo cobrará directamente según [sus precios](https://supabase.com/pricing). Si prefieres que Rork aloje el backend por ti, consulta [Qué es Rork Cloud](/es/backend/rork-cloud).
