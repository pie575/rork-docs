Preguntas frecuentes sobre la exportación de código con Rork

<div id="can-i-export-the-code">
  ### ¿Puedo exportar el código?
</div>

Sí: los usuarios de pago son propietarios de todo el código generado.
¡Descárgalo desde GitHub!

<div id="how-can-i-export-the-code">
  ### ¿Cómo puedo exportar el código?
</div>

Suscríbete a un plan de pago, inicia sesión con GitHub y exporta el código mediante la integración de Rork con GitHub.

<div id="how-can-i-make-changes-locally-and-import-them-back-to-rork">
  ### ¿Cómo puedo hacer cambios en local e importarlos de nuevo a Rork?
</div>

La integración de Rork con GitHub es de **sincronización bidireccional**, así que puedes editar en local e importar los cambios de nuevo a Rork.
