Previsualiza los cambios en local para actualizar tu documentación

<Info>
  **Requisitos previos**:

  * Node.js versión 19 o superior
  * Un repositorio de documentación con un archivo `docs.json`
</Info>

Sigue estos pasos para instalar y ejecutar Mintlify en tu sistema operativo.

<Steps>
  <Step title="Instala la CLI de Mintlify">
    ```bash theme={null}
    npm i -g mint
    ```
  </Step>

  <Step title="Previsualiza en local">
    Ve al directorio de documentación donde se encuentra tu archivo `docs.json` y ejecuta el siguiente comando:

    ```bash theme={null}
    mint dev
    ```

    Tendrás disponible una vista previa local de tu documentación en `http://localhost:3000`.
  </Step>
</Steps>

<div id="custom-ports">
  ## Puertos personalizados
</div>

De forma predeterminada, Mintlify usa el puerto 3000. Puedes cambiar el puerto en el que se ejecuta Mintlify con la opción `--port`. Por ejemplo, para ejecutar Mintlify en el puerto 3333, usa este comando:

```bash theme={null}
mint dev --port 3333
```

Si intentas ejecutar Mintlify en un puerto que ya está en uso, se usará el siguiente puerto disponible:

```md theme={null}
Port 3000 is already in use. Trying 3001 instead.
```

<div id="mintlify-versions">
  ## Versiones de Mintlify
</div>

Ten en cuenta que cada versión de la CLI está asociada a una versión específica de Mintlify. Si tu vista previa local no coincide con la versión de producción, actualiza la CLI:

```bash theme={null}
npm mint update
```

<div id="validating-links">
  ## Validar enlaces
</div>

La CLI puede ayudarte a validar los enlaces de tu documentación. Para detectar enlaces rotos, usa el siguiente comando:

```bash theme={null}
mint broken-links
```

<div id="code-formatting">
  ## Formato del código
</div>

Te recomendamos usar extensiones en tu IDE para reconocer y formatear MDX. Si usas VSCode, prueba la [extensión MDX para VSCode](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx) para el resaltado de sintaxis y [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode) para el formato del código.

<div id="troubleshooting">
  ## Solución de problemas
</div>

<AccordionGroup>
  <Accordion title="Error: No se pudo cargar el módulo &#x22;sharp&#x22; con el entorno de ejecución darwin-arm64">
    Puede que se deba a una versión desactualizada de node. Prueba lo siguiente:

    1. Desinstala la versión de la CLI que tengas instalada: `npm remove -g mint`
    2. Actualiza a Node v19 o superior.
    3. Vuelve a instalar la CLI: `npm i -g mint`
  </Accordion>

  <Accordion title="Problema: Aparece un error desconocido">
    Solución: ve a la raíz de tu dispositivo y elimina la carpeta `~/.mintlify`. Después, vuelve a ejecutar `mint dev`.
  </Accordion>
</AccordionGroup>

¿Quieres saber qué cambió en la última versión de la CLI? Consulta el [registro de cambios de la CLI](https://www.npmjs.com/package/mintlify?activeTab=versions).
