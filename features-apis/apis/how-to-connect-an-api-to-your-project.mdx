APIs let your app do almost anything without you having to build the feature yourself: weather data, SMS, email, AI models, payments, maps, and more. Rork supports two main ways to connect an API.

<Tip>
  Attach the API's documentation to your chat message for the best results. Rork reads the docs and writes the integration code correctly the first time.
</Tip>

## Method 1: Environment variables (simplest)

Use this when the API only needs an API key and does not require a server-side function. This works for many AI APIs, weather APIs, and similar.

<Steps>
  <Step title="Get your API key">
    Sign up at the API provider and copy your API key.
  </Step>
  <Step title="Add it to Rork Secrets">
    Open **More → Secrets** in your project. Click **Add Variable**, enter a name like `OPENAI_API_KEY`, and paste the value. Press **Save**.
  </Step>
  <Step title="Tell Rork to use it">
    Send a prompt like:

    ```text
    Use the OPENAI_API_KEY environment variable to call the OpenAI API and [describe what you want it to do]
    ```
  </Step>
</Steps>

## Method 2: Supabase Edge Functions (for private keys)

Use this when the API key must stay private (payment APIs, SMS, email with secrets). An Edge Function runs on the server, so the key never reaches the user's device.

<Steps>
  <Step title="Connect Supabase to your project">
    If you have not done so already, see [Connect a Supabase backend](/backend/supabase).
  </Step>
  <Step title="Add your API key as a Supabase secret">
    In your Supabase project, go to **Edge Functions** → **Secrets**. Add a new secret with a name like `RESEND_API_KEY` and paste the value.
  </Step>
  <Step title="Ask Rork to write the Edge Function">
    In your Rork project, send:

    ```text
    I want my app to achieve [task] using [API name]. The secret name is [SECRET_NAME].
    Create a Supabase Edge Function for this.
    ```
  </Step>
  <Step title="Deploy the function in Supabase">
    In Supabase, go to **Edge Functions** → **Deploy New Function** → **Editor**. Paste the code Rork wrote, then deploy.
  </Step>
  <Step title="Tell Rork to use the endpoint">
    Copy the deployed function's endpoint URL from Supabase and send it to Rork:

    ```text
    Use this Edge Function to achieve [task] by sending or requesting [data]:
    <endpoint URL here>
    ```
  </Step>
</Steps>

## Troubleshooting

Edge Function integrations often need a few iterations:

- **Data is not being parsed correctly.** Keep prompting until the format is right.
- **Edge function keeps failing.** You may need to rewrite it a few times. Paste the error from the Supabase logs.
- **Invalid API key.** Double-check the key was entered correctly, or redeploy the edge function after updating the secret.
