title: "Подключение API к Rork"

API — это здорово: они позволяют вашим приложениям делать что угодно, при этом вам самим ничего реализовывать не нужно.

<div id="two-main-ways-to-connect-an-api-to-rork">
  ## **Два основных способа подключить API к Rork**
</div>


**Переменные окружения:**
Переменные окружения — это встроенная в Rork поддержка API без подключения backend вроде Supabase. Пользователю достаточно ввести свои API-ключи и сразу получить доступ к нужному API.

<img alt="Image" />

Всё, что нужно сделать, — нажать «Добавить переменную», ввести имя ключа с описанием вашего API, а затем указать значение — сам API-ключ.

После этого попросите Rork использовать edge-функцию.

<Tip>
  Совет: для лучшего результата приложите документацию от поставщика API
</Tip>



**Edge-функция Supabase:**

Подключите Supabase:
Отправьте в Rork запрос «подключи Supabase к приложению», указав Project URL и Public Anon key.

Затем перейдите к edge-функциям:

<img alt="Image" />

В разделе edge-функций нажмите секрет. Задайте имя секрета и укажите свой API-ключ в поле значения.

<img alt="Image" />

Далее скопируйте имя секрета и вставьте его в Rork или ChatGPT с запросом: «Я хочу, чтобы моё приложение выполняло задачу X с помощью этого API. Вот имя моего секрета (вставьте имя), напиши код edge-функции для этого API». 

Затем в Supabase нажмите Deploy New Function:

<img alt="Image" />

Затем нажмите editor:

<img alt="Image" />

Затем удалите предыдущий код:

<img alt="Image" />

Вставьте код из ChatGPT или Rork и нажмите deploy function. После этого скопируйте URL своего эндпоинта и вставьте его в Rork с запросом: «Используй эту Edge-функцию для выполнения задачи X, отправляя или запрашивая данные X: &lt;вставьте ссылку на эндпоинт&gt;»

<img alt="Image" />


**Устранение неполадок:**
Этот способ потребует заметно больше проб и ошибок:

* Данные не парсятся — повторяйте запрос, пока не заработает.
* Edge-функция постоянно падает с ошибкой; возможно, придётся переписать её несколько раз.
* Недействительный API-ключ: вы ошиблись при вводе ключа либо нужно заново развернуть edge-функцию.
