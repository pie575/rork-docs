---
title: "Как протестировать и опубликовать приложение Rork через Xcode"
---

Как открыть ваше iPhone-приложение Rork в Xcode на Mac, запустить его в симуляторе или на своём устройстве, посмотреть логи и создать архив сборки для TestFlight и App Store.

<Info>
  Для публикации Xcode не нужен: Rork сам собирает и отправляет ваше приложение на своих серверах — см. [Публикация приложения в Apple App Store](/ru/store-guides/publish-app-store). Xcode пригодится, если вы хотите детально изучить логи, отладить приложение на своём устройстве или самостоятельно создать архив сборки.
</Info>

<div id="why-do-you-need-xcode">
  ### Зачем нужен Xcode?
</div>

Xcode удобен тем, что позволяет отслеживать логи и детально разбираться, почему приложение работает или не работает. Кроме того, он даёт возможность отправить приложение в App Store в один клик и работает очень эффективно, поскольку это продукт Apple.

**Требования**

* Mac
* Установленный Xcode
* Проект, подключённый к GitHub
* Установленный GitHub Desktop (или `git` в терминале)
* Учётная запись Apple Developer

<div id="installing-xcode">
  ### Установка Xcode
</div>

Скачайте Xcode из App Store

<img alt="Image" />

Затем установите инструменты командной строки и примите условия лицензии:

```shellscript theme={null}
xcode-select --install
sudo xcodebuild -license accept
```

<div id="opening-your-rork-project-in-xcode">
  ### Открытие проекта Rork в Xcode
</div>

Приложения Rork для iPhone — это нативные проекты на Swift, поэтому Xcode открывает их напрямую. Ничего предварительно генерировать не требуется.

Подключитесь к GitHub

<img alt="Image" />

Перейдите на GitHub

<img alt="Image" />

Откройте в GitHub Desktop

<img alt="Image" />

Теперь откройте терминал в папке проекта и выполните:

```shellscript theme={null}
xed .
```

Проект откроется в Xcode. Если в проекте несколько приложений, выполните команду в папке iOS-приложения.

При первом открытии Xcode загружает и разрешает Swift-пакеты, которые использует приложение. Дождитесь завершения этого процесса, прежде чем создавать сборку.

<div id="run-the-app">
  ### Запуск приложения
</div>

* **Симулятор:** выберите симулятор на панели инструментов и нажмите кнопку воспроизведения.
* **Собственный iPhone:** подключите устройство, выберите его на панели инструментов и нажмите кнопку воспроизведения. На устройстве должен быть включён режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**.

Откройте консоль отладки в нижней части окна, чтобы просматривать логи во время работы приложения.

<div id="publish-to-the-app-store-via-testflight">
  ### Публикация в App Store (через TestFlight)
</div>

Откройте меню «Product» и нажмите «Archive».

<img alt="Image" />

По завершении архивации откроется окно Organizer. Выберите **Distribute App**, затем **App Store Connect** — и ваша сборка появится в TestFlight.

<div id="troubleshooting">
  ## Устранение неполадок
</div>

**Сборка завершается ошибкой сразу после открытия проекта.** Возможно, Xcode ещё загружает пакеты Swift. Дождитесь завершения и запустите сборку снова.

**Не удаётся разрешить зависимость пакета Swift.** В Xcode выберите **File → Packages → Reset Package Caches**, затем соберите проект заново.

**Непонятные ошибки сборки от предыдущих запусков.** Очистите папку сборки через **Product → Clean Build Folder** (Shift + Command + K), затем соберите проект заново.

**Ошибки подписи.** Откройте настройки проекта, выберите таргет, перейдите в **Signing &amp; Capabilities** и укажите свою команду Apple Developer.
