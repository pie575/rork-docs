Часто задаваемые вопросы об экспорте кода в Rork

<div id="can-i-export-the-code">
  ### Можно ли экспортировать код?
</div>

Да — весь сгенерированный код принадлежит пользователям платных тарифов.
Скачать его можно через GitHub!

<div id="how-can-i-export-the-code">
  ### Как экспортировать код?
</div>

Оформите платный тариф, войдите через GitHub и экспортируйте код через интеграцию Rork с GitHub.

<div id="how-can-i-make-changes-locally-and-import-them-back-to-rork">
  ### Как вносить изменения локально и импортировать их обратно в Rork?
</div>

Интеграция Rork с GitHub работает как **двусторонняя синхронизация**, поэтому вы можете редактировать проект локально и импортировать изменения обратно в Rork.
