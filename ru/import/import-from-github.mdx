---
title: "Импорт репозитория GitHub в Rork"
---

Как импортировать репозиторий GitHub в Rork и собрать на его основе мобильное приложение: вставьте URL репозитория, подключите GitHub App от Rork и продолжайте работу над существующим проектом с помощью ИИ и двусторонней синхронизации с GitHub.

У вас уже есть код на GitHub — web app, прототип или проект из другого ИИ-конструктора? Начинать с нуля не придётся. Rork импортирует репозиторий GitHub, разберёт исходные файлы и продолжит разработку уже в формате нативного мобильного приложения.

<div id="two-ways-to-import">
  ## Два способа импорта
</div>

| Что нужно сделать...                                                             | Что использовать                                    |
| -------------------------------------------------------------------------------- | --------------------------------------------------- |
| Создать **новый проект Rork** из существующего репозитория                       | Кнопку **GitHub to Mobile App** на главной странице |
| Подключить репозиторий **к существующему проекту Rork** (как связанный источник) | Вставку URL репозитория в чат проекта               |

В обоих случаях работает **GitHub Sync**: Rork остаётся подключённым к репозиторию и читает ваши настоящие исходные файлы, а не строит догадки по скриншотам или описаниям.

<div id="start-a-new-project-from-a-github-repo">
  ## Создание нового проекта из репозитория GitHub
</div>

<div id="1-click-github-to-mobile-app">
  ### 1. Нажмите «GitHub to Mobile App»
</div>

На сайте [rork.com](https://rork.com) под полем запроса нажмите **GitHub to Mobile App**.

<Frame>
  <img alt="Кнопки импорта под полем запроса на главной странице Rork" />
</Frame>

<div id="2-paste-the-repository-url">
  ### 2. Вставьте URL репозитория
</div>

Откроется диалоговое окно **«Create an app from GitHub with Rork»**. Вставьте URL своего репозитория (`https://github.com/owner/repo`).

<Frame>
  <img alt="Диалоговое окно импорта из GitHub со вставленным URL репозитория" />
</Frame>

<div id="3-generate-the-app">
  ### 3. Сгенерируйте приложение
</div>

* **Generate app now** — генерация запускается сразу, либо
* **I have extra requests** — репозиторий прикрепляется к вашему запросу, и вы можете добавить инструкции («импортируй это и сделай дашборд главным экраном»).

Репозиторий прикрепляется к запросу как источник **GitHub Sync**, после чего Rork создаёт проект.

<Frame>
  <img alt="Новый проект, созданный из репозитория GitHub, с прикреплённым источником GitHub Sync" />
</Frame>

<div id="4-grant-access-via-the-rork-github-app">
  ### 4. Предоставьте доступ через Rork GitHub App
</div>

GitHub Sync работает через **Rork GitHub App**, поэтому приложению нужен доступ к репозиторию, который вы импортируете. Агент проведёт вас по всем шагам прямо в чате:

1. Если приложение ещё не установлено, нажмите **Open GitHub** в виджете чата и установите его.
2. Если приложение установлено, но не видит этот репозиторий, нажмите **Update GitHub permissions** и добавьте репозиторий (доступ можно ограничить только им одним).
3. Вернувшись в Rork, нажмите **I&#39;ve updated permissions** / **Retry**, а затем **Continue** для подтверждения.

Когда связь установлена, в строке статуса появляется **«Connected owner/repo»**.

<Info>
  Репозиторий должен находиться в аккаунте или организации GitHub, где вы можете установить Rork GitHub App. Чтобы импортировать чужой публичный репозиторий, сначала сделайте его форк в свой аккаунт и импортируйте форк.
</Info>

<div id="5-the-agent-rebuilds-your-app-from-the-source">
  ### 5. Агент пересобирает приложение из исходного кода
</div>

После подключения агент сканирует переменные окружения, анализирует исходный код (экраны, паттерны, тему, интеграции), создаёт каркас нативного приложения и воспроизводит ваш продукт, переиспользуя реальные ресурсы прямо из репозитория:

<Frame>
  <img alt="Список задач Rork при импорте репозитория" />
</Frame>

Через несколько минут приложение уже работает в облачном симуляторе, нативно пересобранное из вашего репозитория:

<Frame>
  <img alt="Приложение, импортированное из GitHub, работает нативно в симуляторе Rork" />
</Frame>

<div id="import-without-changing-anything">
  ## Импорт без каких-либо изменений
</div>

Описывать изменения при импорте не обязательно. Вставьте URL и нажмите **Generate app now**. Кнопка **I have extra requests** необязательна: попросить о доработках можно и позже, в следующих сообщениях чата.

Что важно знать перед началом: **импорт — это пересборка, а не копирование**. Rork подключает ваш репозиторий как источник только для чтения и пишет новое нативное приложение на основе того, что в нём прочитал. Он не переносит ваши файлы в редактор один за другим. Ваши экраны, сценарии, оформление, модель данных и ассеты сохраняются. Код интерфейса превращается в Swift, Kotlin или React.

Импорт, как и любой другой запрос, расходует кредиты: один кредит уходит на создание проекта, и каждое последующее сообщение агенту тоже стоит кредитов.

<div id="import-a-repo-into-an-existing-project">
  ## Импорт репозитория в существующий проект
</div>

В любом проекте вставьте в чат ссылку на GitHub-репозиторий и попросите агента подключить его, например:

```
Подключи https://github.com/acme/inventory-api и используй его как бэкенд для этого приложения
```

Агент привязывает репозиторий к вашему проекту (связь сохраняется между сессиями), благодаря чему он может читать код, повторно использовать ваши API-контракты и модели данных и поддерживать всё в соответствии с исходным кодом.

<div id="keep-the-sync-two-way">
  ## Держите синхронизацию двусторонней
</div>

GitHub Sync — это не разовое копирование. Когда в подключённом исходном репозитории появляются новые коммиты, проект уведомит вас, и вы сможете загрузить их одним кликом:

<Frame>
  <img alt="Уведомление GitHub Sync: доступны новые изменения, Sync now" />
</Frame>

А подключив проект Rork к его собственному репозиторию GitHub, вы получите полноценную **двустороннюю синхронизацию**:

* Каждое изменение, внесённое Rork, отправляется в GitHub.
* Коммиты, которые вы отправляете из своего редактора, импортируются обратно в Rork.

Чтобы настроить её в проекте: **меню ⋯ → GitHub → Connect**.

<Frame>
  <img alt="Опция двусторонней синхронизации с GitHub в меню проекта" />
</Frame>

Полное пошаговое руководство: [Как синхронизировать проект с GitHub](/ru/tutorials/how-to-connect-github).

<div id="what-kinds-of-repos-work-best">
  ## Какие репозитории подходят лучше всего?
</div>

* **Веб-приложения** (React, Vue, Next.js — всё, у чего есть читаемый исходный код): Rork пересобирает продукт в виде нативного мобильного приложения.
* **Результат работы других ИИ-конструкторов** (Lovable, Bolt, v0, Replit и другие): см. [Импорт из любого конструктора приложений](/ru/import/import-from-any-app-builder).
* **Проекты React Native / Expo**: агент читает исходный код и пересобирает его в нативное приложение на Swift или Kotlin, см. [Перенос между платформами](/ru/import/convert-between-platforms).
* **Нативные проекты на Swift или Kotlin**: агент читает ваш существующий нативный код и заново собирает приложение в Rork. Он не подхватывает ваш проект Xcode или Android Studio как есть, поэтому считайте импорт созданием нового нативного приложения, которое воспроизводит ваш продукт.
* **Бэкенды / API**: подключите их как источник, чтобы ваше мобильное приложение в точности соответствовало API.

<div id="faq">
  ## Частые вопросы
</div>

<div id="how-does-github-to-mobile-app-work">
  ### Как работает GitHub to Mobile App?
</div>

В четыре шага. Вы вставляете URL своего репозитория в диалоговое окно **GitHub to Mobile App** на [rork.com](https://rork.com). Затем предоставляете приложению Rork GitHub App доступ к этому репозиторию. Агент читает реальные исходные файлы и анализирует экраны, тему, интеграции и переменные окружения. После этого он собирает нативное приложение на основе найденного и сохраняет связь с репозиторием, чтобы вы могли подтягивать новые коммиты.

<div id="does-importing-change-my-repository">
  ### Изменяет ли импорт мой репозиторий?
</div>

Нет. При импорте Rork только читает ваш код. Отправлять изменения в репозиторий Rork будет, только если вы явно подключите для проекта двустороннюю синхронизацию, — и это будет отдельный репозиторий, созданный Rork (или выбранный вами).

<div id="which-plan-do-i-need-to-import-a-repo">
  ### Какой тариф нужен для импорта репозитория?
</div>

Импорт не привязан к конкретному тарифу. Он расходует кредиты, как обычный запрос. Но платный тариф всё же нужен: при импорте создаётся работающее приложение, а тариф **Free** позволяет только проектировать приложения.

Разница в том, для какой платформы вы разрабатываете. **Rork Pro** ($20/месяц) охватывает iPhone (SwiftUI), Android (Kotlin + Compose) и Web. **Rork Max** добавляет iPad, Apple Watch, Vision Pro, нативные игры, виджеты iOS и приоритетную поддержку в чате. То есть нативный репозиторий на Swift прекрасно импортируется и на Rork Pro, а Rork Max нужен только ради дополнительных устройств Apple и функций, доступных исключительно в Max. См. [Тарифы и подписки](/ru/introduction/subscriptions).

<div id="can-i-import-a-monorepo">
  ### Можно ли импортировать монорепозиторий?
</div>

Да. Укажите в запросе, какая папка или какое приложение внутри монорепозитория вас интересует, чтобы агент работал с нужным кодом.

<div id="the-repo-isnt-found-or-access-fails">
  ### Репозиторий не найден или нет доступа
</div>

* Проверьте, что URL имеет вид `https://github.com/owner/repo` (суффикс `.git` не нужен, а ветки и подпапки можно указать в запросе).
* Для приватных репозиториев убедитесь, что приложение Rork GitHub App установлено **в аккаунте или организации, которой принадлежит репозиторий**, и имеет доступ к этому конкретному репозиторию.
