---
title: "Какие возможности backend есть у Rork?"
---

Rork предоставляет опциональную backend-инфраструктуру для приложений, которым требуется серверная логика. Сейчас она находится в стадии бета-тестирования, поэтому при возникновении любых проблем обращайтесь в службу поддержки.

<div id="overview">
  ### **Обзор**
</div>

Backend позволяет разработчикам реализовать собственную серверную логику, API-эндпоинты и работу с базой данных прямо в приложениях Rork.

<div id="capabilities">
  ### **Возможности**
</div>

* **API-эндпоинты** — определение собственных маршрутов для взаимодействия клиента и сервера
* **Серверная логика** — выполнение защищённых операций вне клиентского приложения
* **Интеграция с базой данных** — надёжное хранение и получение данных
* **Защищённые маршруты** — поддержка аутентификации и авторизации

<div id="technical-stack">
  ### **Технологический стек**
</div>

| **Компонент**       | **Технология** |
| :------------------ | :------------- |
| Серверный фреймворк | Hono           |
| API-слой            | tRPC           |

<div id="when-to-use">
  ### **Когда использовать**
</div>

Backend рекомендуется для:

* Социальных приложений с взаимодействием между пользователями
* Многопользовательских функций и совместной работы в реальном времени
* Приложений, которым需要 общее или централизованное хранилище данных

**Backend не требуется для:**

* Однопользовательских приложений
* Сценариев с локальным хранением данных
* Приложений, использующих только встроенные ИИ-функции

<div id="ai-capabilities">
  ### **Возможности ИИ**
</div>

Чтобы добавить в приложение возможности ИИ, используйте **Rork Toolkit**. В Toolkit уже есть готовые ИИ-функции: генерация текста, создание изображений, преобразование речи в текст и умные ассистенты — и всё это без какой-либо настройки backend.

<div id="whats-inside-the-rork-toolkit">
  ## Что входит в Rork Toolkit?
</div>

| **Возможность**                               | **Модель**             | **Провайдер** |
| :-------------------------------------------- | :--------------------- | :------------ |
| **ИИ-ассистент (чат/агент)**                  | Claude Sonnet 4.5      | Anthropic     |
| **Генерация текста**                          | GPT-5 Chat             | OpenAI        |
| **Извлечение данных (generateObject)**        | GPT-4.1                | OpenAI        |
| **Генерация изображений**                     | GPT-Image-1.5 (DALL-E) | OpenAI        |
| **Редактирование изображений**                | Gemini 2.5 Flash Image | Google        |
| **Преобразование речи в текст**               | Whisper-1              | OpenAI        |
| **Обобщение результатов работы инструментов** | Gemini 2.5 Flash       | Google        |

Доступ к моделям осуществляется через следующие функции SDK набора инструментов:

* Anthropic Claude Sonnet 4.5 — для чата и агентных сценариев
* OpenAI GPT-5 — для генерации текста
* OpenAI GPT-4.1 — для извлечения структурированных данных
* Генерация изображений — OpenAI DALL-E
* Редактирование изображений — Gemini 2.5 Flash Image
* Распознавание речи — OpenAI Whisper-1

**Что можно создать с помощью Rork Toolkit**

С Rork Toolkit можно создавать полноценные приложения на базе ИИ — чат-агентов, генераторы контента, инструменты извлечения данных, функции работы с изображениями и голосом, мультимодальные сценарии — и всё это в рамках одного набора инструментов. Здесь есть всё необходимое, чтобы делать умные, готовые к продакшену ИИ-решения и не жонглировать десятком моделей и провайдеров.
