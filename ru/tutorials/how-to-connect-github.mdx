Полное руководство по подключению проекта Rork к GitHub для двусторонней синхронизации

<div id="why-would-you-want-to-enable-github-sync">
  ## Зачем включать синхронизацию с GitHub?
</div>

Подключите **GitHub**, если хотите вывести приложение за пределы редактора Rork и работать с ним в привычных инструментах разработки.

<div id="github-lets-you">
  ### GitHub позволяет:
</div>

* **Передать проект разработчику** для совместной работы или кастомизации
* **Открыть и редактировать приложение в Cursor или любом редакторе кода**
* **Запускать и отлаживать проект в Xcode** для разработки под iOS
* **Вносить изменения на уровне кода**, выходящие за рамки разработки с помощью промптов

GitHub служит мостом между **Rork** и профессиональными процессами разработки: он упрощает передачу проекта, кастомизацию и нативную разработку.

Если вы работаете исключительно внутри Rork, GitHub не обязателен.
Если же вам нужен более полный контроль, совместная работа или нативные инструменты — подключить его стоит.

<div id="what-you-can-do-now">
  ## Что теперь можно делать
</div>

После подключения GitHub ваш проект в Rork больше не ограничен редактором Rork. Теперь вы можете:

* **Передать проект разработчику**
  Поделитесь репозиторием, чтобы разработчик мог клонировать его, вносить правки и отправлять изменения.
* **Открыть проект в Cursor или другом редакторе кода**
  Изучайте и меняйте сгенерированный код в Cursor, VS Code или любой другой IDE.
* **Запускать и отлаживать приложение в Xcode**
  Собирайте приложение локально, тестируйте на реальных устройствах и используйте нативные инструменты отладки Apple.
* **Настраивать приложение не только промптами**
  Вносите точечные изменения на уровне кода, добавляйте нативные функции или оптимизируйте производительность.
* **Работать параллельно с Rork**
  Продолжайте разработку в Rork, пока правки вносятся через GitHub.

Благодаря этой интеграции вы сможете в любой удобный момент плавно перейти от **разработки с помощью промптов к полному контролю над кодом**.
