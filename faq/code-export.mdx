Frequently Asked Questions about code export with Rork

### Can I export the code?

Yes — paid users own all generated code.\
Download it via GitHub!

### How can I export the code?

Subscribe to a paid plan, sign in with GitHub, and export through the Rork GitHub integration.

### How can I make changes locally and import them back to Rork?

Rork’s GitHub integration is **two-way sync** — so you can edit locally and import changes back to Rork.
