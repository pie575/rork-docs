These are the most common questions about exporting code from Rork.

<AccordionGroup>
  <Accordion title="Can I export the code?">
    Yes. Paid users own all generated code. You can export it through the Rork GitHub integration.
  </Accordion>

  <Accordion title="How can I export the code?">
    Subscribe to a paid plan, sign in with GitHub, and export through the Rork GitHub integration. From there you get a real repository with the full Swift, Kotlin, or React codebase.
  </Accordion>

  <Accordion title="How can I make changes locally and import them back to Rork?">
    The Rork GitHub integration is two-way sync: you can edit locally and import changes back to Rork. Your local edits appear in the Rork editor and are visible to the agent.
  </Accordion>

  <Accordion title="Can I use the exported code without Rork?">
    Yes. The exported code is real Swift, Kotlin, or React that works independently. You can open a Swift project in Xcode, a Kotlin project in Android Studio, or a React project in any editor.
  </Accordion>

  <Accordion title="Do I own the code on the Free plan?">
    Code export requires a paid plan. On the Free plan, you can design apps but cannot export the underlying code.
  </Accordion>
</AccordionGroup>
