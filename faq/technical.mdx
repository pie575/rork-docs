These are the most common technical questions about how Rork builds apps.

<AccordionGroup>
  <Accordion title="Are Rork apps actually native iOS/Android? Or are they web apps?">
    They are real native apps. Rork writes SwiftUI for iPhone and Kotlin with Jetpack Compose for Android: the same languages Apple and Google use for their own apps. New projects are Swift, Kotlin, or web. They are not websites wrapped in a webview.

    Native code delivers smooth animations, responsive interfaces, and immediate access to the latest platform features, from widgets and Live Activities on iOS to Material You theming and background work on Android.

    Rork also builds web apps in React when the product belongs in a browser. Those are web apps by design, published to your own address instead of an app store. See [iPhone, Android, or web: what's the difference](/swift-vs-react-native/whats-the-difference).
  </Accordion>

  <Accordion title="Can I use Rork to build production-ready apps?">
    Yes. Rork supports apps ranging from 0 to 100,000 users. Apps built with Rork are live on the App Store and Google Play with real paying customers.
  </Accordion>

  <Accordion title="Does it work on iOS and Android?">
    Yes. An iPhone app and an Android app are two separate native apps, and one Rork project can hold both. Ask for the second platform at any time and the agent rebuilds your screens and flows in it. See [Convert your app between iOS, Android, and web](/import/convert-between-platforms).
  </Accordion>

  <Accordion title="I have an older Expo (React Native) project. Does it still work?">
    Yes. Rork no longer creates new Expo projects, but the ones you already have keep working: you can build them, publish them, and export the code to GitHub. If you want Swift or Kotlin instead, ask the agent to add a native iPhone or Android app to the project.
  </Accordion>

  <Accordion title="What are the limits of the browser preview?">
    The browser preview is great for seeing how your app looks and feels quickly. However, the preview may not match the native app exactly, and some native features (camera, Bluetooth, push notifications, background tasks) are not available in the browser. Test on a real device or in the iOS/Android simulator for accurate results.
  </Accordion>
</AccordionGroup>
