关于使用 Rork 导出代码的常见问题

<div id="can-i-export-the-code">
  ### 我可以导出代码吗？
</div>

可以——付费用户拥有全部生成的代码。
通过 GitHub 即可下载！

<div id="how-can-i-export-the-code">
  ### 如何导出代码？
</div>

订阅付费套餐，使用 GitHub 登录，然后通过 Rork 的 GitHub 集成导出代码。

<div id="how-can-i-make-changes-locally-and-import-them-back-to-rork">
  ### 如何在本地修改并将改动导入回 Rork？
</div>

Rork 的 GitHub 集成支持**双向同步**——因此你可以在本地编辑，再把改动导入回 Rork。
