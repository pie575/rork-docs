<div id="build-apps-from-your-phone">
  ### 用手机构建应用
</div>

完整的 Rork Max 聊天体验，专为 iPhone 重新设计：计划、待办、提问和构建进度一应俱全。你可以新建一个应用，也可以打开任何已经做好的应用，随时接着往下做。所有应用、会话及其最新状态都在 **Apps** 标签页中等着你。每个 项目 都会标明它是 **Swift**、**Web** 还是两者兼有。

点按 **+**，描述你想构建什么。创建之前先选择平台：

聊天的用法与网页版 Rork Max 完全一致：

* **语音输入**：不用打字，直接口述消息，然后发送，或先编辑再发。
* **图片与标注**：附上照片，或直接在聊天中截取运行中应用的画面并在上面涂画，精确指出你想改动的地方。
* **文件上传**：直接从&quot;文件&quot;应用附加文档 (规格说明、CSV、设计稿) ，让智能体基于它们工作。
* **计划模式**：让智能体先提出方案，在写任何代码之前交给你审阅。
* **模型选择器**：为每条消息单独选择 AI 模型，或保持 Auto。
* **消息队列**：智能体工作期间，你可以继续发送后续消息。它们会排列在输入框上方，逐条执行。点按排队中的消息可以编辑，或在它开始前点按 **X** 将其移除。
* **智能体组件**：智能体可以向你提问、索取 API 密钥、为你的应用生成图片、音效和 3D 模型，并实时展示 构建进度，这一切都在聊天中完成。

附件和设置都收在消息输入框旁边的 **+** 按钮里：

  ### 原生预览，无需 TestFlight
</div>

Swift build 在 app 内原生运行。速度满帧、手势真实，没有串流，也不是模拟器。你测试的就是真实的 app，而不是它的视频画面。

Swift app 运行时，一个悬浮的橙色 Rork 按钮会始终显示在最上层 (挡住内容时可随意拖动) ：

* **点按**打开聊天，继续迭代你的 app。
* **长按**退出正在运行的 app，返回 app 列表。

  ### 用手机发布到 App Store
</div>

打开 **More → Publish App** 进入 **App Store Submissions**，或者直接在聊天中让智能体帮你发布应用。在提交中心，你可以发起新的提交、跟踪上传进度、打开 TestFlight，并把 **Beta Invite Link** 分享给测试人员。

点击 **New Submission**，依次填写 App Info (平台、图标、名称、版本) ，连接你的 Apple Developer 账号，然后上传。整个过程中，聊天组件还能帮你处理 App Store 元数据、截图和合规事项。

Swift 应用可以直接从手机发布到 App Store。Web 应用可以在 Rork Max 和浏览器中预览，但不能通过此流程提交到 App Store。

<div id="how-to-install-the-rork-max-app">
  ## 如何安装 Rork Max 应用
</div>

Rork Max 会把你构建的 app 以真正的原生代码在自身内部运行，正因如此它无法上架 App Store。你只需通过浏览器安装一次即可，整个过程约五分钟，也不用在电脑上下载任何东西。

所有操作都在同一个页面完成：前往 **[rork.com/ios/install](https://rork.com/ios/install?utm_source=docs\&utm_medium=referral\&utm_campaign=rork-max-app\&utm_content=install-section)**，按页面上的步骤操作即可。

电脑只需用这一次。之后一切都在你的 iPhone 上进行：Rork Max 会通过无线方式自动更新，新功能会在你下次打开 app 时直接出现。不用连数据线，也不用重装。

偶尔我们会发布无法通过无线方式推送的 Rork Max 应用 新版本。遇到这种情况，只需重新访问 [rork.com/ios/install](https://rork.com/ios/install?utm_source=docs\&utm_medium=referral\&utm_campaign=rork-max-app\&utm_content=install-section-reinstall)，再运行一次安装即可。安装的始终是最新版本，并会替换你手机上的旧版本。

<div id="requirements">
  ## 要求
</div>

* 一台运行 **iOS 18 或更高版本**的 iPhone (可在“设置 → 通用 → 关于本机”中查看)
* 一台**装有 Chrome 或 Edge 的 Mac**，用于一次性安装 (暂不支持 Windows)
* 一根 **USB 数据线**，最好是 iPhone 随附的原装线或任何通过 MFi 认证的线缆 (仅供充电的线缆无法使用)
* 一个免费或付费的 **Apple Developer 账号**。免费账号最多可同时保留 3 个侧载安装的 app；付费会员则没有此限制
* 构建 Swift app 需要**付费的 Rork 订阅方案**。**Rork Pro** (每月 $20) 已涵盖原生 iPhone app：详见[定价](https://rork.com/pricing?utm_source=docs\&utm_medium=referral\&utm_campaign=rork-max-app\&utm_content=requirements-pricing)

<Info>
  在 Mac 上使用 Chrome 或 Edge 时，你不再需要 Rork Companion 桌面应用。从安装 Rork Max 到把 app 装进 iPhone，整个流程都在浏览器和 app 内完成。Companion 只保留给安装程序暂不支持的浏览器使用：详见[使用 Companion 应用进行测试](/zh/rork-max-swift)。
</Info>

  <Accordion title="它只能在 iPhone 上使用吗？">

  </Accordion>

  <Accordion title="我需要 Mac 还是 Windows 电脑？">

  </Accordion>

  <Accordion title="我需要在电脑上安装任何东西吗？">
    不用。无需下载任何东西，整个安装过程都在浏览器里完成。只要用 USB 数据线连接 iPhone，再按[安装页面](https://rork.com/ios/install?utm_source=docs\&utm_medium=referral\&utm_campaign=rork-max-app\&utm_content=faq-install)上的步骤操作即可。

  <Accordion title="使用 Apple Account 登录安全吗？">
    是的。你的 Apple 凭据、证书和配对数据都保存在浏览器中，app 签名也在你的本机上完成，不会有任何数据发送到 Rork 的服务器。
  </Accordion>

  <Accordion title="我需要付费的 Apple Developer 账户吗？">
    不需要，免费和付费的 Apple Developer 账号都可以使用。唯一的区别是：免费账号同时最多只能保留 3 个侧载安装的 app，而付费会员没有这个限制。

  <Accordion title="需要使用原装数据线吗？">
    建议使用：iPhone 原装数据线，或任何通过 MFi 认证的数据线。必须是数据线，而不是仅能充电的线缆。使用未认证的线缆时，安装过程中可能出现连接中断，我们无法保证能正常工作。
  </Accordion>

  <Accordion title="Rork Companion 怎么了？">
    如果你在 Mac 上使用 Chrome 或 Edge，就不再需要 Companion 了。从安装 Rork Max 到把 app 装到 iPhone 上，现在所有操作都能在浏览器和 app 内完成。Companion 只保留给安装程序尚未支持的浏览器：参见[使用 Companion app 进行测试](/zh/rork-max-swift)。
  </Accordion>

  <Accordion title="我真的可以通过 Rork Max 将完整的 app 安装到 iPhone 上吗？">
    是的，真的可以。你构建的 app 会作为真正的 iOS 应用出现在主屏幕上。你可以像打开其他应用一样启动它们，并立即测试小组件、相机、灵动岛等原生功能。
  </Accordion>

  <Accordion title="我可以在 Rork Max app 中构建 Web app 吗？">
    可以。点击 **+** 后，平台选择 **Web** (或在 Apps 标签页中打开已有的 Web 项目) 。Web 应用可以在 Rork Max 内预览，也可以从 Project Actions 中在浏览器里打开。不过小组件、灵动岛这类 Apple 原生功能仍然需要 Swift 应用。
  </Accordion>

  <Accordion title="它只能运行 Swift 应用吗？">
    不是。Rork Max 同时支持 **Swift** 和 **Web** 项目。Swift 可解锁 Apple 原生功能：小组件、实时活动、ARKit、HealthKit，甚至 3D 游戏。不确定该选哪个？请参阅 [iPhone、Android 还是 web：有什么区别](/zh/swift-vs-react-native/whats-the-difference)。
  </Accordion>

  <Accordion title="我可以用手机发布到 App Store 吗？">
    Swift 应用可以。打开 **More → Publish App**，然后通过 **App Store Submissions** 上传构建版本、使用 TestFlight 并获取测试邀请链接。你也可以直接在聊天中让智能体帮你发布应用，它会引导你完成整个提交流程。Web 应用不通过此流程发布到 App Store。
  </Accordion>

  <Accordion title="更新如何进行？">
    Rork Max 的大多数版本更新都通过 OTA (空中下载) 自动完成。只需安装一次，下次打开应用时新功能便会自动出现。个别情况下，宿主程序的更新需要重新访问 [rork.com/ios/install](https://rork.com/ios/install?utm_source=docs\&utm_medium=referral\&utm_campaign=rork-max-app\&utm_content=faq-updates) 安装一次；此次安装会覆盖手机上原有的应用。
  </Accordion>

  <Accordion title="为什么我的 iPhone 上会出现多个 Rork Max app？">
    每次安装都会与你签名时使用的 Apple Developer 团队绑定，因此如果你曾用不同的 Apple 账户或团队安装 Rork Max，每一次安装都会显示为一个独立的 app。只要使用相同的 Rork 账户和相同的 Apple 团队重新安装，就会覆盖已有的 app，而不会新增一个。不用的副本可以放心删除，但要注意：免费的 Apple Developer 账户同时最多只能安装 3 个侧载 app。
  </Accordion>

  <Accordion title="我没有收到 Apple 的短信验证码">
    与其干等短信，不如直接从受信任的设备上获取验证码：在任意已登录的 iPhone、iPad 或 Mac 上，前往 **设置 → 你的姓名 → 登录与安全性 → 获取验证码**。Apple 的[验证码指南](https://support.apple.com/102606)逐一说明了各种方式。仍未解决？请联系 [Apple 账户支持](https://support.apple.com/apple-account)，短信下发由 Apple 一方负责。
  </Accordion>

  <Accordion title="安装后 App 无法启动">
    需要检查两点。第一，在 iPhone 上信任该开发者：**设置 → 通用 → VPN 与设备管理** → 点按你的账户 → **信任**。第二，确认已开启开发者模式：**设置 → 隐私与安全性 → 开发者模式**。另外，如果你用的是免费的 Apple Developer 账户，Apple 只允许同时侧载 3 个 app，你可能已经达到上限。付费的 [Apple Developer Program](https://developer.apple.com/programs/) (99 美元/年) 则没有此限制。
  </Accordion>

  <Accordion title="安装后如何使用？">
    灵感来临时，随时打开 Rork Max 即可。你的所有 app、会话及其最新状态都原封不动地等在那里。
  </Accordion>
