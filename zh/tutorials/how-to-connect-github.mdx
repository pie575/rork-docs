完整指南：如何将 Rork 项目连接到 GitHub，实现双向同步

<div id="why-would-you-want-to-enable-github-sync">
  ## 为什么要启用 GitHub 同步？
</div>

如果你希望把 Rork 应用带出 Rork 编辑器，放到传统开发工具中继续开发，就可以连接 **GitHub**。

<div id="github-lets-you">
  ### GitHub 让你可以：
</div>

* **把项目分享给开发者**，进行协作或定制开发
* **在 Cursor 或任意代码编辑器中打开并编辑你的应用**
* **在 Xcode 中运行和调试项目**，用于 iOS 开发
* **进行代码层面的修改**，突破仅靠基于提示词的构建的限制

GitHub 是连接 **Rork** 与专业开发流程的桥梁，让项目交接、定制和原生开发更加顺畅。

如果你的工作完全在 Rork 内完成，GitHub 是可选项。
如果你想要更深入的控制、协作能力或原生开发工具，则建议启用。

<div id="what-you-can-do-now">
  ## 现在你可以做什么
</div>

连接 GitHub 后，你的 Rork 项目就不再局限于 Rork 编辑器。现在你可以：

* **把项目交给开发者**
  分享仓库，让开发者克隆、编辑并推送更改。
* **在 Cursor 或代码编辑器中打开项目**
  使用 Cursor、VS Code 或任意 IDE 查看和修改生成的代码。
* **在 Xcode 中运行和调试应用**
  在本地构建、在真机上测试，并使用 Apple 的原生调试工具。
* **超越提示词进行自定义**
  做出精确到代码层面的修改、添加原生功能，或对性能进行微调。
* **与 Rork 并行推进**
  在通过 GitHub 进行编辑的同时，继续在 Rork 中构建。

只要你准备好，这项集成就能让你从**基于提示词的构建平滑过渡到完全的代码掌控**。
