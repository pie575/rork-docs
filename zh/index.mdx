  # 快速开始

**Rork 是什么？**

Rork 是一个无需写代码就能构建和发布应用的平台，支持原生 iPhone 应用、原生 Android 应用和 Web 应用。

你不用雇工程师，也不用学编程，只需用日常语言描述你想要的应用。Rork 会帮你写好应用、做好设计、跑完 build，并发布到 App Store、Google Play 或你自己的网址上。不用装 Xcode，不用配 Android 工具链，也不用搭建构建流水线——一切都在浏览器里完成。

过去需要数月时间、一整支团队和大笔资金才能做成的事，如今一个人就能快速搞定。你只管专注创意和产品决策，实现和发布交给 Rork。

如果你有一个应用创意，想让它真正上线，Rork 能为你扫清一路上的成本、时间和复杂度障碍。
