Rork is an AI-powered app builder. You describe your idea in plain language and Rork writes native Swift, Kotlin, or React code, handles the build, and publishes it directly to the App Store, Google Play, or the web. No team required.

## What Rork builds

Rork generates three kinds of real, native apps. Each one is the same code a mobile studio would write by hand.

<CardGroup cols={3}>
  <Card title="For iPhone" icon="apple" href="/swift-vs-react-native/whats-the-difference">
    Native SwiftUI apps for iPhone, iPad, Apple Watch, and Vision Pro. Ships to the App Store.
  </Card>

  <Card title="For Android" icon="android" href="/android/rork-android">
    Native Kotlin + Compose apps for Android phones and tablets. Ships to Google Play.
  </Card>

  <Card title="For Web" icon="globe" href="/web/rork-web">
    React + Vite web apps at your own `rork.app` address. Live in seconds, no review required.
  </Card>
</CardGroup>
