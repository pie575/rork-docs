<Note>
  Rork can publish to the App Store and TestFlight without Xcode. This guide is for developers who want to run the app locally, use Apple's native debugger, or make code-level changes in Xcode.
</Note>

Xcode is Apple's native IDE for iOS development. By connecting your Rork project to Xcode through GitHub, you can run your app on a real device, inspect crashes with the debugger, and make precise code-level changes.

## What you need

- A Mac running macOS 13 or later
- Xcode installed from the Mac App Store (free)
- A paid Apple Developer account for device testing
- Your Rork project connected to GitHub (see [GitHub Sync](/tutorials/how-to-connect-github))

## Connect and run your app in Xcode

<Steps>
  <Step title="Connect your project to GitHub">
    In your Rork project, click **Integrations → Connect with GitHub** and follow the steps. See [GitHub Sync](/tutorials/how-to-connect-github).
  </Step>
  <Step title="Clone the repository">
    Open Terminal and run:

    ```bash
    git clone https://github.com/your-org/your-repo
    cd your-repo
    ```
  </Step>
  <Step title="Open the Xcode project">
    In Xcode, go to **File → Open** and select the `.xcodeproj` or `.xcworkspace` file inside the repo.
  </Step>
  <Step title="Set up signing">
    Select your project in the file tree, open the **Signing and Capabilities** tab, and sign in with your Apple Developer account. Xcode creates the signing certificate and provisioning profile automatically.
  </Step>
  <Step title="Run on a real device">
    Connect your iPhone via USB. Select it as the run destination in the toolbar and press **Cmd + R**. Xcode builds and installs the app.
  </Step>
  <Step title="Debug with the console">
    Use the Xcode console and debugger to inspect crashes, set breakpoints, and see log output in real time.
  </Step>
</Steps>

<Tip>
  Changes you make in Xcode and push to GitHub flow back into the Rork editor automatically through two-way sync.
</Tip>
