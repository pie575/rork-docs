Connect GitHub if you want to take your Rork app beyond the editor and into traditional development tools. If you are staying fully inside Rork, GitHub is optional. If you want deeper control, collaboration, or native tooling, it is recommended.

## Why connect GitHub

Connecting GitHub unlocks several workflows:

- Share your project with a developer for collaboration or customization
- Open and edit the app in Cursor, VS Code, or any code editor
- Run and debug the project in Xcode for iOS development
- Make code-level changes beyond what prompts can accomplish
- Work in parallel: continue prompting in Rork while edits flow through GitHub

## Connect your project to GitHub

<Steps>
  <Step title="Click Integrations">
    In your Rork project, click **Integrations**.
  </Step>
  <Step title="Click Connect with GitHub">
    Select **Connect with GitHub**.
  </Step>
  <Step title="Install and authorize">
    GitHub opens in a new tab. Create an account if you need one, then click **Install and Authorize**.
  </Step>
  <Step title="Name your repository">
    After redirecting back to Rork, name your repository.
  </Step>
  <Step title="Done">
    Your project is now connected to GitHub. Two-way sync begins automatically.
  </Step>
</Steps>

<Note>
  Edits you push to the GitHub repository come back into the Rork project automatically through two-way sync.
</Note>

## What you can do now

Once connected, you can:

- **Hand the project to a developer.** Share the repository so they can clone, edit, and push changes.
- **Open in Cursor or VS Code.** Work in the code editor you already know.
- **Run and debug in Xcode.** Test on real devices and use Apple's native debugger.
- **Customize beyond prompts.** Make precise code-level edits the agent cannot express.
- **Work in parallel.** Keep prompting in Rork while a developer works in the repository.
