## Before you submitBefore you submit

1. **App icon** — 1024 x 1024 PNG, no transparency. Generate one in Rork or upload your own.
2. **App name and subtitle** — set these in Project Settings before building.
3. **Bundle identifier** — must match the App ID you created in App Store Connect.
4. **Version number** — use 1.0 for a first submission.
5. **Screenshots** — at minimum, provide iPhone 6.7-inch (1290 x 2796) screenshots. See the [App Store Screenshots guide](/appstore-screenshots/app-store-screenshots).
6. **Privacy policy URL** — required for all apps. See [how to set up your policies](/make-your-app-profitable/paywalls/how-to-set-up-your-policies).
7. **In-app purchase setup** — if your app has a paywall, configure subscriptions in App Store Connect before submitting. See the [RevenueCat guide](/payment-guides/revenuecat-copied-1).
8. **Run AI App Store Reviewer** — scan for guideline violations before you send the app for review. See [AI App Store Reviewer](/ai-app-store-reviewer).

## Common rejection reasonsommon rejection reasons

<AccordionGroup>
  <Accordion title="Guideline 4.2 - Minimum Functionality">
    Apps that do nothing meaningful or are just a website wrapper are rejected. Fix: add real native features, such as camera access, push notifications, or local storage.
  </Accordion>

  <Accordion title="Guideline 5.1.1 - Account deletion">
    If your app has user accounts, it must include an in-app account deletion flow. A link to a web form is not enough.
  </Accordion>

  <Accordion title="Missing privacy policy">
    A privacy policy is required if you collect any user data, use analytics, or offer accounts. Link it in App Store Connect and inside the app.
  </Accordion>

  <Accordion title="Paywall without mention in description">
    If all core features require a subscription, state that clearly in the App Store description so users know before downloading.
  </Accordion>

  <Accordion title="Test account not provided">
    If your app requires login, include a working test account in the Review Notes section of App Store Connect.
  </Accordion>
</AccordionGroup>
