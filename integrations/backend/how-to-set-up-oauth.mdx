This guide walks you through adding social sign-in (Apple and Google) to your Rork app using Supabase Auth.

## Prerequisites

You need:

- A **Supabase project**
- Your **Supabase Project URL** and **Anon/Public key**
- Access to **Google Cloud Console** (for Google OAuth Client ID and Secret)
- An **Apple Developer account** (for Sign in with Apple)

## Step 1: Connect Rork to Supabase

1. In Supabase, copy your **Project URL** and **Public anon key**.
2. In Rork, send this prompt:

```text
Connect to Supabase. Here is my Project URL: [paste] and anon key: [paste]
```

This is required before you configure any OAuth providers.

## Step 2: Enable Google sign-in in Supabase

1. Go to **Supabase → Authentication → Sign-in / Providers** and enable **Google**.

### Create Google OAuth credentials

1. Go to **Google Cloud Console** and create a new OAuth client.
2. Choose **Web application**.
3. Copy the **Client ID** and **Client Secret**.

### Configure Supabase and get the callback URL

1. Paste the **Client ID** and **Client Secret** into the Google provider settings in Supabase.
2. Copy the **Callback/Redirect URL** from Supabase.
3. Back in Google Cloud Console, add that URL to **Authorized redirect URIs**.

## Step 3: Add a sign-in screen in Rork

In Rork, prompt:

```text
Add a sign-in page before the user accesses the app.
Google: <SUPABASE_CALLBACK_URL>
```

## Step 4: Enable Apple sign-in

1. In **Supabase → Authentication → Sign-in Providers**, enable **Apple**.

### Create an Apple key

In **Apple Developer**:

1. Go to **Keys** and click **Add Key**.
2. Enable **Sign in with Apple**, select your app, and continue.
3. Register the key, then download and save it.

### Enable Sign in with Apple on your App ID

1. In Apple Developer, go to **Identifiers → your App ID**.
2. Enable **Sign in with Apple** and save.

### Add your Bundle ID to Supabase

1. Copy your **Bundle ID** from Apple Developer.
2. In **Supabase → Apple provider**, paste the Bundle ID as the **Client ID** and save.
3. Copy the **Apple callback URL** from Supabase.

## Step 5: Add Google and Apple OAuth in Rork

Now that both providers are configured in Supabase, prompt Rork to add them:

```text
Add Google and Apple OAuth using Supabase.
Google: <SUPABASE_GOOGLE_CALLBACK_URL>
Apple: <SUPABASE_APPLE_CALLBACK_URL>
```

## Step 6: Test and fix common issues

### Issue: Google opens Safari and fails to connect

If you see "Safari can't open the page because it cannot connect to the server", enable **new users to sign up** in the Supabase Auth settings. After enabling signups, Google sign-in should complete and bring the user back into the app.

### Issue: Apple opens Safari and says "missing OAuth secret"

This happens when the flow is using a web-based OAuth path instead of native Sign in with Apple.

Fix:

```text
Redo Apple sign-in as native only. Do not use a web browser for Apple sign-in.
```

After this, Apple sign-in should appear in the native Apple UI, not Safari.
