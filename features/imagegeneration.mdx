Rork makes it easy to generate visual assets for your app or add AI image generation functionality that your users can interact with. There are two main use cases: generating your app icon, and adding image generation features inside your app.

## Generate your app icon

You can create a custom app icon using AI in two ways.

**Option 1: Ask in chat** Send a message to the Rork agent describing what you want. For example:

> "Please update our app icon by generating an image for it. Make it a minimalist mountain silhouette with a sunset gradient."

**Option 2: Use the Generate Icon option** Click your project title in the top-left corner, then select **Generate Icon**. This opens a dialog where you can describe the icon you want, and Rork generates it for you.

Once generated, the icon automatically transfers to your published App Store app.

## Add image generation to your app

You can add text-to-image or image-to-image generation functions that your users can trigger from inside the app.

For example, you might prompt Rork with something like this:

> "Please add an AI image generator for this camera app. When a user takes a photo, instead of returning the actual photo, generate a polaroid version of that image. Ask the user what celebrity they want in the picture before generating the image."

Rork will scaffold the UI and wire up the generation function so your users get the transformed result.
