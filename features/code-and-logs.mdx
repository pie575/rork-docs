Open **More > Code** to see the actual project: a file tree, the source of every file, and a runtime logs panel. There are four moments when opening the code editor is especially useful: when you want to inspect a bug, check a value, hand the project to a developer, or simply satisfy your curiosity.

## Read the tree

The code editor shows one folder per app in your project. Inside you will find an ordinary codebase with folders like `src/`, `components/`, `pages/`, and files like `package.json`. The `.rork/` directory is hidden except for `.rork/DESIGN.md`, which you can read.

## Edit by hand

<Note>
  Editing code requires a paid plan. On the free plan, the editor is read-only and displays a banner explaining the restriction.
</Note>

On a paid plan, the editor is writable. Make your change and press **Cmd+S** (or **Ctrl+S**) to saveOn a paid plan, the editor is writable. Make your change and press **Cmd+S** (or **Ctrl+S**) to save.

There are two important rules when editing by hand:There are two important rules when editing by hand:

1. **You cannot save while the agent is working.** Wait for the current agent turn to finish before saving.
2. **Rork sees your edit on the next turn.** The agent takes your hand-edited code into account during its next response.

<Warning>
  Hand edits have no undo of their own. **Reset All** will discard unsaved changes. After you save, the edit becomes a permanent part of the project. When possible, ask the agent to make the change instead, because agent-made changes are tracked as revertible versions.
</Warning>

## Read the logs

The **Logs** panel sits at the bottom of the code editor. It shows everything your app printed while running in the preview, updated in real time. Each log line is tagged by level:The **Logs** panel sits at the bottom of the code editor. It shows everything your app printed while running in the preview, updated in real time. Each log line is tagged by level:

- `[log]`
- `[info]`
- `[warn]`
- `[error]`
- `[debug]`

This is often the best way to understand a bug that the agent cannot see from the UI alone.

## Take the code with you

Connect GitHub to export your project as a normal repository, with one commit per agent turn. This makes it easy to collaborate with developers, open the code in your favorite editor, or run it in native tooling. For instructions, see [Sync Your Rork Project with GitHub](/tutorials/how-to-connect-github).

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I edit code on the free plan?">
    No. The code editor is read-only on the free plan. Upgrade to a paid plan to enable writable editing.
  </Accordion>

  <Accordion title="Can I edit code while the agent is running?">
    No. You must wait for the current agent turn to finish before saving any hand edits.
  </Accordion>

  <Accordion title="Where are my environment variables?">
    Environment variables are stored in **Secrets**, not in the code. See [API Keys](/features/secrets) for how to manage them.
  </Accordion>
</AccordionGroup>
