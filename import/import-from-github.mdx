Already have code on GitHub? A web app, a prototype, or a project from another AI builder? Rork can import a GitHub repository, inspect the actual source files, and continue building natively from what it finds.

## Ways to import

| Approach | When to use it |
| --- | --- |
| Start a new Rork project from a repo | Click the **GitHub to Mobile App** button when creating a new project |
| Pull a repo into an existing project | Paste the repository URL directly into your project chat |

## Start a new project from a GitHub repo

Follow these steps to turn an existing GitHub repository into a native mobile app:

<Steps>
  <Step title="Click GitHub to Mobile App">
    On rork.com, look for the **GitHub to Mobile App** button under the prompt box and click it.
  </Step>
  <Step title="Paste the repository URL">
    Enter the full repository URL, for example `https://github.com/owner/repo`, into the dialog.
  </Step>
  <Step title="Start generating">
    Click **Generate app now**, or choose **I have extra requests** to add additional instructions first.
  </Step>
  <Step title="Grant access via the Rork GitHub App">
    Install the Rork GitHub App if you have not already, or click **Update GitHub permissions** to add the repository. The status shows **Connected owner/repo** when the connection is live.

    The repository must be in a GitHub account where you can install the Rork GitHub App. To import someone else's public repo, fork it into your own account first.
  </Step>
  <Step title="Let the agent rebuild">
    Rork scans your repository: it reads environment variables, audits the source, scaffolds a native app, and reproduces your product from the real assets it finds.
  </Step>
</Steps>

<Note>
  Import is a rebuild, not a copy. Rork connects your repository as a read-only source and writes a fresh native app from what it reads. Your screens, flows, branding, data model, and assets carry over. The underlying UI code becomes Swift, Kotlin, or React.
</Note>
